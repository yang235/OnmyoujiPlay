============================================
  OnmyoujiPlay 绿色便携包 打包说明
============================================

一、打包方案
────────────────────────────────────────────
  保留完整项目源码结构，内嵌 Python 运行时 +
  全部第三方依赖，通过 start.bat 启动 tk UI。

  目录结构：
    OnmyoujiPlay_portable/
    ├── start.bat              # 双击启动
    ├── runtime/               # Python 3.8 + 依赖
    │   ├── python.exe
    │   ├── python3.dll
    │   ├── python38.dll
    │   ├── DLLs/              # _tkinter 等 C 扩展
    │   ├── tcl/               # Tcl/Tk 运行时
    │   └── Lib/               # site-packages + 标准库
    ├── anasis/                # 模板图片 + 工具
    ├── game_actions/          # 动作模块
    ├── ui_control/            # UI + 窗口控制
    └── main.py


二、打包步骤
────────────────────────────────────────────

  1. 创建输出目录
     mkdir dist\OnmyoujiPlay_portable\runtime

  2. 复制 Python 运行时
     cp <conda_env>\python.exe  dist\...\runtime\
     cp <conda_env>\python3.dll dist\...\runtime\
     cp <conda_env>\python38.dll dist\...\runtime\

  3. 复制标准库 + 第三方包
     cp -r <conda_env>\Lib      dist\...\runtime\

  4. 复制 C 扩展 (含 _tkinter.pyd)
     cp -r <conda_env>\DLLs      dist\...\runtime\

  5. 复制 Tcl/Tk 运行时 (tkinter 依赖)
     cp -r <conda_env>\tcl       dist\...\runtime\

  6. 复制项目源码
     cp -r anasis/ game_actions/ ui_control/ main.py dist\...\
     (排除 __pycache__)

  7. 创建 start.bat (内容见第四节)


三、start.bat 说明
────────────────────────────────────────────
  必须设置的环境变量：

    PYTHONHOME  = runtime 目录        (Python 找标准库)
    PYTHONPATH  = 项目根目录           (找到 anasis/game_actions 包)
    PATH        = runtime + DLLs + Lib (找 python.exe + C 扩展 DLL)
    TCL_LIBRARY = tcl\tcl8.6          (tkinter 依赖)
    TK_LIBRARY  = tcl\tk8.6           (tkinter 依赖)

  关键点：PYTHONPATH 必须指向 bat 所在目录，否则 tk.py
  运行时找不到同级的 anasis、game_actions 包。


四、start.bat 完整内容
────────────────────────────────────────────
@echo off
chcp 65001 >nul
set "PYTHONHOME=%~dp0runtime"
set "PYTHONPATH=%~dp0"
set "PATH=%~dp0runtime;%~dp0runtime\DLLs;%~dp0runtime\Lib;%PATH%"
set "TCL_LIBRARY=%~dp0runtime\tcl\tcl8.6"
set "TK_LIBRARY=%~dp0runtime\tcl\tk8.6"
if not exist "%~dp0output" mkdir "%~dp0output"
if not exist "%~dp0output\gouxie" mkdir "%~dp0output\gouxie"
"%~dp0runtime\python.exe" "%~dp0ui_control\ui\tk.py"
pause

	============================================
	  实际操作记录 (2026-05-18)
	============================================

	六、只打包依赖（不包含项目文件）
	────────────────────────────────────────────
	  本次操作仅打包 Python 运行时 + 第三方依赖，
	  不复制项目源码 (anasis/game_actions/ui_control/main.py)。

	  源环境: D:\anaconda3\envs\oop (Python 3.8.20)
	  输出目录: dist\OnmyoujiPlay_portable\runtime\

	  执行命令:
	    1. mkdir -p dist\OnmyoujiPlay_portable\runtime
	    2. cp <env>\python.exe <env>\python3.dll <env>\python38.dll → runtime\
	    3. cp -r <env>\DLLs → runtime\
	    4. cp -r <env>\tcl  → runtime\
	    5. cp -r <env>\Lib  → runtime\
	    6. find runtime -type d -name "__pycache__" -exec rm -rf {} +

	  最终产物: runtime\ (9.6GB)
	    ├── python.exe
	    ├── python3.dll
	    ├── python38.dll
	    ├── DLLs\          (_tkinter.pyd 等 C 扩展)
	    ├── Lib\           (标准库 + site-packages)
	    │   └── site-packages\  (opencv, paddleocr, pywin32,
	    │                         pywinauto, pillow, PaddleOCR ...)
	    └── tcl\           (tcl8.6, tk8.6)

	  使用方式: 将项目源码目录 (anasis/game_actions/ui_control/main.py)
	  与 runtime\ 放在同级，配合 start.bat 即可运行。
